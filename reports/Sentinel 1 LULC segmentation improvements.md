# Fix the protocol, then exploit time

**Fix the evaluation and training protocol first, then put the remaining budget into better use of the time series.** Those two steps offer the best expected gain per hour for the Sentinel-1-only U-Net. A loss swap, a bigger backbone or a foundation model offers less. The current evidence cannot yet separate the variants. The 15-epoch PCA run (test mIoU 0.544) and the 60-epoch three-month baseline (0.559) differ by about 1.5 points. Validation mIoU swings by about 7 points between epochs, so that 1.5-point gap is within noise. The near-free fixes come first, because they make every later ablation readable: an EMA copy of the weights, a fixed warmup-plus-cosine schedule, a deterministic full-tile validation pass, and inference that averages predictions over all monthly windows and overlapping tiles. The literature reports about +1 to +1.6 mIoU each for EMA and longer fixed-schedule training. The largest documented single lever for SAR is a learned temporal encoder over the full 12-month series (U-TAE). It beats single-date and 3D-CNN baselines by large margins and fits easily on a T4. Cheap temporal-statistic channels and class-aware copy-paste target the three weak classes (wetland, shrub/grass, cropland). Terrain inputs belong in an optional, clearly labelled ablation. The realistic ceiling matters for the exam write-up. The two label products are each only about 74-77% correct against expert reference, and they are weakest on exactly the classes this model struggles with. A gain of about 3-6 mIoU over the current model, to roughly 0.58-0.62 on the agreement-filtered test set, is a credible target. Anything near 0.70 would be suspicious.

## A 7-point validation swing hides every gain under about 2 mIoU

The most urgent problem is measurement, not the model. Validation mIoU moved from 0.656 to 0.583 between epochs, and the PCA-vs-baseline test difference is about 1.5 mIoU. Most of the published improvements below are also in the 0.3-2 mIoU range. Under the current protocol, the project cannot tell whether any change helped. The validation swing most likely reflects sampling noise from few validation sites and random crops, not real changes in the model. The fix is cheap: evaluate every validation tile in full, with a deterministic sliding window over all available month windows, and pick checkpoints by a smoothed signal rather than a single epoch.

Weight averaging is the standard tool for a noisy curve and costs almost nothing. A 2025 challenge report validated and saved an **EMA copy of the weights (decay 0.999)** and gained **+1.08 mIoU**. The authors also observed fewer speckle-like artefacts in large homogeneous regions ([arXiv 2505.11769](https://arxiv.org/pdf/2505.11769)). Stochastic weight averaging gave **+0.77 mIoU** over a single model on BDD100K ([arXiv 2207.11211](https://arxiv.org/pdf/2207.11211)). A TMLR study found EMA models more robust to noisy labels and better calibrated ([arXiv 2411.18704](https://arxiv.org/pdf/2411.18704)), which fits labels built from two imperfect map products. With about 125-156 optimiser steps per epoch, a decay of 0.998-0.999 averages over several epochs. The EMA must also cover the BatchNorm buffers, or the BN statistics must be recomputed.

The learning-rate schedule is the second protocol fix. ReduceLROnPlateau reacts to the noisy validation signal, so lucky or unlucky epochs move the learning rate. A fixed schedule of 1-2 warmup epochs, then cosine decay to about 1e-6 over a fixed epoch count, removes that coupling. The closest published analogue is the winner of the IEEE DFC2025 SAR land-cover track. It is SAR-only, uses noisy optical-derived pseudo-labels, and so resembles this setup. There, training longer (40k to 160k iterations) gave **+1.57 val mIoU**. That beat both the loss change and the larger backbone in the same ablation ([arXiv 2504.13458](https://arxiv.org/html/2504.13458v1)). Practically, the 15-epoch DEV runs are too short to rank variants. Final comparisons should use the same epoch budget as the 60-epoch baseline, with the same schedule for every variant.

No direct study was found that compares checkpoint selection by validation loss with selection by validation mIoU under noisy labels. The reasoning still favours mIoU on the EMA model. With class weights, validation loss mostly tracks calibration, not segmentation quality. If the budget allows only one run per variant, the report should state openly that differences below about 1-2 mIoU fall within run-to-run noise.

## Time is the strongest SAR lever, and the model uses only part of it

Across benchmarks, the most consistent gain for SAR comes from temporal information, not from architecture or pretraining. On PASTIS, the U-TAE temporal-attention U-Net reaches **63.1 mIoU**. A 3D-UNet reaches **58.4** and a single-date U-Net only **28.3**. Replacing the learned temporal attention with a plain temporal mean costs 3 points. U-TAE has only **about 1.1 M parameters** and was the fastest temporal model compared ([arXiv 2107.07933](https://ar5iv.labs.arxiv.org/html/2107.07933)). With Sentinel-1 input only, U-TAE scores **53.8-54.9 mIoU** on PASTIS-R, using raw VV, VH and VV/VH with no speckle filter or terrain correction ([arXiv 2112.07558](https://arxiv.org/html/2112.07558v1)). On the S1-only BraDD-S1TS dataset, U-TAE beats 3D-UNet by 2.6 mIoU and ConvLSTM by 7 ([arXiv 2412.14123](https://arxiv.org/html/2412.14123)). In PANGAEA, aggregating time with an L-TAE instead of linear stacking lifted CROMA's SAR-only score on a crop-type task from **35.4 to 50.4 mIoU**, overtaking the optical model ([arXiv 2412.04204](https://arxiv.org/html/2412.04204v2)). The negative example confirms the pattern. A global model trained on Dynamic World labels with a single annual-mean VV+VH composite reached only **23.6 mIoU** S1-only ([arXiv 2410.03962](https://arxiv.org/html/2410.03962)).

The current design is a hand-built version of this idea. It uses three stacked months plus six PCA components of the year. It already beats annual-mean inputs, which helps explain why the model's 0.54-0.56 is far above SpecSAR's 23.6, alongside the easier, agreement-filtered labels. However, PCA fixes one global weighting of the months for every pixel. U-TAE learns a per-pixel attention over months. That suits the three weak classes, which are all defined by seasonality: flooding cycles for wetland, growth and harvest for cropland, and greening for shrub/grass. One caution applies. No published study compares U-TAE directly with a stacked-channel ImageNet ResNet U-Net on Sentinel-1, so the size of the gain on this dataset is unknown until tested. The PASTIS single-date baseline was a from-scratch U-Net on one date, which is a much weaker reference than the current model. U-TAE also depends heavily on its normalisation. **BatchNorm instead of GroupNorm collapsed PASTIS mIoU from 63.1 to 36.0** ([arXiv 2107.07933](https://ar5iv.labs.arxiv.org/html/2107.07933)).

U-TAE must still produce 12 monthly maps. The cheapest option fits the existing loop: feed a centred window of 5-7 months and predict the centre month, then slide the window 12 times with wrap-around padding at the year edges. A more elegant option encodes the whole year once and adds a month embedding at the decoder. The labels are annual (WorldCover and Dynamic World 2021), so the monthly maps mostly differ through smoothing and seasonal classes such as snow. The exam report should say this explicitly.

Two cheaper temporal measures come before U-TAE. First, **temporal-statistic channels** can be computed offline from the downloaded monthly stack, with no new GEE export: VH standard deviation, VV minimum and maximum, the VH p90-p10 range, and the fraction of months below a water threshold. A controlled study of 3,843 Sentinel-1 wetland experiments found that using all within-year observations beat summarised temporal forms. Temporal form mattered more than feature choice, and plain σVV/σVH beat derived polarimetric measures ([Li et al. 2020](https://rsc4earth.de/publication/li-discriminating-2020/)). Statistics therefore complement the stack rather than replace it. Their value is inductive bias. VH amplitude separates cropland from temporally stable trees, and min/max separates seasonally flooded wetland from permanent water. They can replace some PCA components to keep the channel count flat. Compute them from linear backscatter, not dB. Second, **inference-time window ensembling**: average the softmax over all ten 3-month windows of the year to predict the annual label. This matches the annual target directly and costs only inference time. It is untested in the literature, but the cost is minimal and the reasoning is sound. The same idea applies at training time. If training always uses one fixed window position, sampling a random window per patch adds free data and seasonal invariance.

## Losses, encoders and foundation models move the needle by one or two points

The DFC2025 SAR winner shows the realistic size of the smaller tweaks. Adding Lovász-softmax to cross-entropy gave **+0.29 mIoU**, and adding symmetric cross-entropy for label noise gave **+0.19**. One round of self-training with their own pseudo-labels gave **+0.80**, and ensembling gave **+0.61** over the best single model ([arXiv 2504.13458](https://arxiv.org/html/2504.13458v1)). On Pascal VOC, Lovász reported about **+1 to +2.5 mIoU** over cross-entropy, although the extracted table was partly garbled ([arXiv 1705.08790](https://arxiv.org/pdf/1705.08790)). Lovász directly optimises IoU, and smp provides it with an `ignore_index`. Replacing the Dice term with it is a one-line, zero-cost experiment, worth about +0.3 to +1.5 mIoU at most. The agreement mask already removes most label noise. The remaining problem is that the clean pixels are biased toward easy classes. Noise-robust losses (SCE, GCE, label smoothing) therefore have little left to fix. Focal loss and OHEM could even hurt, because in noisy labels the "hard" pixels are often the mislabelled ones. The notes also flag a smaller issue: square-root median-frequency class weights combined with a WeightedRandomSampler count rarity twice. One ablation without one of them is worthwhile.

Pretrained SAR encoders give a similar modest gain. On the DFC2020-S1 land-cover task in Copernicus-Bench, SAR-pretrained ViT-B models (SoftCon **52.8**, CROMA **52.7**, Copernicus-FM **52.4 mIoU**) beat a supervised ViT-B (**50.8**) by about 2 points and random initialisation (**45.4**) by about 7 ([arXiv 2503.11849](https://arxiv.org/html/2503.11849)). The current encoder is ImageNet-pretrained, not random, so the realistic gain sits at the low end. Earlier semi-supervised pretraining on DFC2020 raised optical-only average accuracy by about 8 points but SAR-only by only **1.5 (54.8 to 56.3)** ([arXiv 2108.09075](https://arxiv.org/html/2108.09075v2)). PANGAEA found a plain U-Net from scratch in the top two on 6 of 11 datasets, more often than any foundation model ([arXiv 2412.04204](https://arxiv.org/html/2412.04204v2)). TerraMind's own ablation scored S1-only at only **20.04 mIoU on PASTIS vs 40.20 for S2-only** ([arXiv 2504.11171](https://arxiv.org/html/2504.11171)). Large ViT foundation models (CROMA 350 M, TerraMind, AnySat 125 M) therefore cost too much on a T4 for too little expected gain. The one practical encoder swap is TorchGeo's 2-channel SSL4EO-S12 `SENTINEL1_ALL_MOCO` ResNet-50 ([TorchGeo](https://torchgeo.readthedocs.io/en/v0.5.1/_modules/torchgeo/models/resnet.html)). It fits best as a shared per-month encoder inside a U-TAE-style model. Forcing its 2-channel first convolution onto 15 stacked channels loses much of the benefit of pretraining.

Decoder and backbone swaps are second-order. The one multi-architecture Sentinel-1 study found the top four models within 0.6 OA points of each other. DeepLabV3+ and PSPNet trailed by about 1-1.4 points. On the peatland (wetland-like) class, producer's accuracy ranged from 42% with DeepLabV3+ to 65% with FC-DenseNet and FRRN-B ([arXiv 1912.05067](https://ar5iv.labs.arxiv.org/html/1912.05067)). Keep the U-Net. Swapping ResNet-34 for ResNet-50 or ConvNeXt-T is likely worth at most 1-2 mIoU.

Two data-side tricks target the weak classes more directly. **Class-aware copy-paste** raised a U-Net on monthly DynamicEarthNet time series from **37.9 to 44.1 mIoU** ([arXiv 2404.05693](https://arxiv.org/abs/2404.05693)). That is the largest single augmentation gain found. Pasting wetland, shrub/grass and cropland regions with their full temporal stacks into other patches costs about 30 lines in the Dataset. The gain may not transfer, because SAR context at paste edges can look unnatural. **One-round offline self-training** addresses the about 18% of pixels ignored as disagreement. Predict them with the EMA model and TTA. Keep pixels with confidence above about 0.9 whose prediction matches one of the two source labels. Then fine-tune. This is the cheap version of the DFC2025 winner's +0.80 step, and it puts training signal into the classes where the products disagree. No study has tested it on WorldCover/Dynamic World disagreement, so it is an experiment, not an expected result.

## Inference tricks are cheap but small

The 12 monthly maps for arbitrary locations depend on inference quality, separate from test mIoU. Overlapping sliding windows (stride 32 px, 75% overlap) gave **about +1%** and removed tile seams ([arXiv 1711.08681](https://arxiv.org/pdf/1711.08681)). ResUNet-a uses the same idea because edge pixels lack context ([arXiv 1904.00592](https://arxiv.org/pdf/1904.00592)). A 50% overlap with a Hann or Gaussian weight map is a sensible default and costs minutes on a T4. Flip TTA is inconsistent. It added only +0.0005 mIoU in one 2026 segmentation study, where full 8-view D4 lost 0.0047 ([arXiv 2603.14132](https://arxiv.org/pdf/2603.14132)), but +1.6% in a LiDAR study ([arXiv 2405.14870](https://arxiv.org/pdf/2405.14870)). Use 4-view flip TTA only if it helps on validation. For the monthly product, temporal smoothing across months makes maps consistent, either by majority voting over a 3-5 month window or with a sticky HMM. Studies show HMMs remove most illogical land-cover transitions ([Gong et al. 2017](https://www.mdpi.com/2220-9964/6/10/292); [Lamarche et al. 2022](https://research.dial.uclouvain.be/handle/2078.5/240783)). Smoothing improves map plausibility, not annual-label mIoU, and should be presented that way.

## Terrain is an honest ablation, not a hidden input

Static terrain layers are the most common auxiliary inputs in SAR and wetland mapping. Present them as "Sentinel-1 backscatter plus static terrain context", always next to the pure S1 result, not as part of the main model. There is precedent. A published wide-area Sentinel-1 land-cover benchmark packs two S1 channels plus a DEM into its "SAR RGB-DEM" imagelets ([arXiv 1912.05067](https://arxiv.org/pdf/1912.05067v2)). An Alberta wetland CNN built in GEE feeds DEM, TPI, TRI, TWI and valley-bottom flatness with S1 VH ([DeLancey et al. 2020](https://mdpi-res.com/d_attachment/remotesensing/remotesensing-12-00002/article_deploy/remotesensing-12-00002.pdf)). The evidence for a gain is weaker than its popularity suggests, though. The Finland S1 study found that adding a DEM made only a marginal difference ([arXiv 1912.05067](https://ar5iv.labs.arxiv.org/html/1912.05067)). The large HAND gain for SAR flood mapping (about +36% accuracy) comes from a search snippet that the researchers could not verify in the full text ([MDPI rs12040644](https://mdpi-res.com/d_attachment/remotesensing/remotesensing-12-00644/article_deploy/remotesensing-12-00644.pdf)).

The physical reasoning is targeted rather than general. Height above nearest drainage (HAND) and slope separate low, flat wetland and water from uplands. They should mainly remove false water or wetland in radar shadow on slopes. HAND does not separate wetland from open water, because both are low and flat. Elevation is a strong prior for snow and ice. The channels are cheap: 3-4 static layers (Copernicus GLO-30 elevation, slope via `ee.Terrain`, MERIT Hydro HAND) that are tiny next to the monthly stack and available globally at inference time. The researchers did not confirm the exact GEE asset IDs in this pass, so check them before export. Encode aspect as sine and cosine, or drop it. Gamma0 terrain flattening with the Mullissa et al. GEE S1-ARD code is a related preprocessing upgrade for mountain tiles ([Mullissa et al. 2021](https://doaj.org/article/103f5e1094994facba05434cdd914e81); [GitHub](https://github.com/adugnag/gee_s1_ard)). It keeps the input "Sentinel-1 only", but it requires a full re-export and heavier live inference. No source quantified its gain for land cover.

Several popular SAR features are low priority here. VH/VV ratios and the GRD radar vegetation index are fixed functions of VV and VH, and the model already sees VV-VH in dB, which equals the log ratio. True dual-pol H/alpha and DpRVI need SLC covariance data that GEE does not host ([ESA SNAP RVI help](https://step.esa.int/main/wp-content/help/versions/9.0.0/snap-toolboxes/org.csa.rstb.rstb.op.polarimetric.tools.ui/operators/RVIOp.html)). GLCM texture helps shallow classifiers but has no CNN ablation and some negative reports ([STEP forum](https://forum.step.esa.int/t/glcm-worsening-accuracy-results/8247)). Global InSAR coherence exists only at about 92.7 m for Dec 2019-Nov 2020 ([GEE catalog](https://developers.google.com/earth-engine/datasets/catalog/Earth_Big_Data_GLOBAL_SEASONAL_S1_V2019_COHERENCE)), which mismatches both the 10 m grid and the 2021 labels. Single-date speckle-filter gains of about 10 OA points ([KIOST](https://sciwatch.kiost.ac.kr/handle/2020.kiost/42247)) do not transfer to monthly multi-scene composites, which are already temporally multilooked.

## Prioritised experiment plan

Gains are estimates drawn from the analogues above, not guarantees for this dataset. Run each step as a single change against the step before it. Run the 60-epoch configuration with the same seed set, and log per-class test IoU every time. Steps 0-3 fit into two or three Kaggle sessions. Steps 4-7 are optional, depending on remaining time.

| # | Change in `Prototype.ipynb` | Targets | Expected effect | Cost |
|---|---|---|---|---|
| 0 | Deterministic validation: full val tiles, sliding window, all month windows; select by EMA-model val mIoU (or 3-epoch moving average); 2 seeds for final variants | Measurement | Val swing drops from about 7 points to well under 2; makes every later comparison readable | ~30 min code; 2x runs for seeds |
| 1 | EMA of weights (`timm.utils.ModelEmaV2` or `AveragedModel`, decay 0.998-0.999, incl. BN buffers); replace ReduceLROnPlateau with 1-2 epoch warmup + cosine to 1e-6; equal epoch budget (60) for all variants | All classes | +0.5 to +1.5 mIoU, stable curve | ~20 min code, 0 extra run time |
| 2 | Inference: average softmax over all 3-month windows for the annual label; 50% overlap + Hann blending; 4-view flip TTA only if val improves | All, especially seasonal classes | +0.5 to +2 mIoU (window ensembling is untested) | ~1 h code, minutes of inference |
| 3 | Replace Dice with Lovász-softmax (smp `LovaszLoss`, `ignore_index`); one ablation dropping either sampler or class weights | Weak-class IoU | +0.3 to +1.5 mIoU | ~15 min, 1 run each |
| 4 | Temporal-stat channels from linear monthly stack (VH std, VV min/max, VH p90-p10, fraction of months below water threshold); replace 3-4 PCA components; random window position during training | Cropland vs trees, wetland vs water | +0.5 to +2 mIoU overall, larger on cropland and wetland (no published ablation) | ~1 h, offline from existing data |
| 5 | U-TAE over 12 monthly composites (GroupNorm), centred 5-7 month window for each monthly map; PCA removed | Wetland, cropland, shrub/grass | Largest upside; plausibly +2 to +5 mIoU, unknown until tested | 3-5 h code, 1-2 h run |
| 6 | Class-aware copy-paste of wetland / shrub-grass / cropland regions (full temporal stacks), or one-round self-training on disagreement pixels (conf. > 0.9, prediction equals WC or DW label) | Weak classes | +0.5 to +2 mIoU; copy-paste up to +6 in one optical analogue | ~1 h code + 1 run each |
| 7 | Optional ablation: + GLO-30 elevation, slope, MERIT HAND (static, 3 ch), reported as "S1 + terrain" beside the S1-only result | Wetland/water vs shadow, snow | Uncertain; 0 to +2 mIoU, concentrated in snow and wetland | ~1-2 h incl. GEE re-export of aux layers |

Skip these for the exam: large ViT foundation models (TerraMind, CROMA, AnySat), GLCM texture, polarimetric ratios, coherence, focal loss and OHEM, and multi-seed ensembles as the headline model. The SSL4EO-S12 S1 ResNet-50 is worth trying only as the shared per-month encoder in step 5, not as a drop-in for the 15-channel stack.

## Realistic ceilings and honest reporting

The labels set the ceiling, not the radar. ESA WorldCover 2021 reaches **76.7% global OA** against independent reference. Its shrubland user's and producer's accuracy are only **49.1 / 46.9%**, and herbaceous wetland only **30.5 / 44.6%** ([WorldCover PVR v2.0](https://esa-worldcover.s3.eu-central-1.amazonaws.com/v200/2021/docs/WorldCover_PVR_V2.0.pdf)). Dynamic World agrees with expert consensus on **73.8%** of pixels. Its grass precision and recall are about **30%**, and flooded-vegetation recall is **36.8%** ([Brown et al. 2022](https://pmc.ncbi.nlm.nih.gov/articles/PMC9184477/)). The model's weakest classes (wetland 0.22, shrub/grass 0.34) are the products' weakest classes. Part of the low IoU is therefore label disagreement that no SAR model can learn away. Agreement filtering raises label purity, but it also removes the hard pixels from the test set. A related study using all-maps-agree labels reports **0.93-0.97 OA** for an S1-only Swin-Unet in three regions ([Russo et al. 2025](https://arxiv.org/html/2503.07230v1)). Expert-labelled S1-only benchmarks sit far lower: about 55-56% average accuracy on DFC2020 ([arXiv 2108.09075](https://arxiv.org/html/2108.09075v2)), 50-53 mIoU on DFC2020-S1 ([arXiv 2503.11849](https://arxiv.org/html/2503.11849)), and 23.6 mIoU on Dynamic World expert tiles ([arXiv 2410.03962](https://arxiv.org/html/2410.03962)). On the agreement-filtered test set, about **0.58-0.62 mIoU** is a credible target after the plan above. Against an independent expert reference, the honest expectation is roughly **75-80% OA at best**, with shrub/grass and wetland near 0.3-0.5 F1.

The exam report should name the metric precisely. "OA 0.83" means agreement with the WorldCover-Dynamic World consensus on pixels where both agree, and it excludes about 18% of pixels. It is not accuracy against ground truth. Report per-class IoU and a confusion matrix, not only the means. Report the spread across seeds, or state the noise floor. If time allows, report per-site mIoU spread, and also report scores on the disagreement pixels against each product separately. Do not place the numbers in a table next to DFC2020 or SpecSAR results as if they were comparable. Instead, explain why the numbers are higher: easier labels, multi-temporal input and a merged shrub/grass class. Keep the S1-only model as the headline result. Show terrain only as a labelled ablation. Describe the 12 monthly maps as monthly inference of an annual-label model, smoothed over time. Do not present them as validated monthly land cover.

## Conclusion

The biggest gap in this project is weak measurement, not a missing technique. With a 7-point validation swing and single runs, the PCA variant cannot yet be called better or worse than the baseline, and neither can any of the 1-2 point tricks in the literature. Once EMA, a fixed schedule and deterministic validation make differences visible, the evidence points clearly toward time as the main lever. SAR separates cropland, wetland and grassland mainly by how backscatter changes across the year. Learned temporal attention and explicit seasonal statistics exploit that more directly than six global PCA components.

The label analysis also changes the framing of the exam result. A 0.22 wetland IoU looks like a model failure, but it partly reflects two reference products that are themselves unreliable on that class. A report that shows this, together with a well-controlled ablation table and modest, noise-aware gains, will be more convincing than a higher headline number.
